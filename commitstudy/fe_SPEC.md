## 試験の概要(試験要綱 Ver.5.6 と IPA のウェブページで確認済み)
- 実施方式: CBT(Computer Based Testing)方式で **通年・随時** 実施。受験者が試験日時と会場を選んで申し込む(申込みは株式会社シー・ビー・ティ・ソリューションズのサイト)。受験手数料 7,500円(税込)。身体の不自由等で CBT を受けられない人向けに筆記の特別措置試験がある。
- 再受験(リテイクポリシー): 前回の受験日の翌日から起算して30日を超えた日以降を受験日に指定できる。
- 科目A(知識): 90分・60問・多肢選択式(四肢択一)。評価は56問で行い、残り4問は今後の出題のための評価に使う。
- 科目B(技能): 100分・20問・多肢選択式(選択肢は4つとは限らない。ア〜コなど)。評価は19問、残り1問は評価用。分野別出題数は「アルゴリズムとプログラミング」16問、「情報セキュリティ」4問。プログラム言語は **擬似言語**。
- 同じ日に科目A→科目Bの順で受ける。CBT では科目Aの終了後、最長10分の休憩を取れる。
- 採点: IRT(Item Response Theory:項目応答理論)に基づき評価点を出す(問題ごとの配点はない)。合格基準は **科目A・科目B の評価点がどちらも 600点以上(各1,000点満点)**。
- 科目A免除制度: IPA が認定した講座を受講し、修了試験(科目A相当)に合格するなどの基準を満たすと、科目Aが **1年間** 免除される(D/summary_fe_menjo.txt)。2027年度の新試験でもこの制度は変更しない予定。
- 科目Aの出題範囲: 共通キャリア・スキルフレームワークの23の中分類すべて(技術レベル2)。うち「セキュリティ」が重点分野。
- 対象者像(要綱): 「IT を活用したサービス，製品，システム及びソフトウェアを作る人材に必要な基本的知識・技能をもち，実践的な活用能力を身に付けた者」。共通キャリア・スキルフレームワークのレベル2。
- お知らせ(2026年11月時点): CBT のシステムリプレースのため、2026年12月28日から試験を一時休止し、2027年1月下旬に再開予定(申込みは1月中旬以降)。

## 本文HTMLの書き方

各項目の `html` は、<article> と <h3> を除いた中身。次の順で並べる:
1. `<div class="co talk">…</div>` キャラの掛け合い(4〜6行)。

   - 表情は任意で `data-f="smile|eager|sad|surprise|sweat|think|wink"` を p に付ける。

2. `<p class="one">` その分野を一言で説明する1〜2文。
3. `<div class="co tips"><p><b class="lab">たとえるなら</b>…</p></div>` 身近なたとえ。
4. 本体: `<h4>見出し</h4>` と `<ul>`/`<ol class="steps">`/表 `<div class="tw"><table><thead><tr><th>…</th></tr></thead><tr><td>…</td></tr></table></div>` を組み合わせる。知識は1つの <li> に1つ。
   - 計算の手順は `<ol class="steps">` で1段ずつ書く(例: 10進数→2進数の変換、稼働率の計算)。数式は全角記号を避け、×・÷・≦・≧ などはシラバスや擬似言語の記述形式と同じ記号を使う。
   - プログラム(擬似言語)は `<pre><code>…</code></pre>` に書く(< > & はエスケープ)。擬似言語は D/shiken_yougo_ver5_1.txt 別紙2 の記述形式(○手続名、型名: 変数名、←、if/elseif/else/endif、while/endwhile、do/while、for/endfor、mod、and/or/not、配列の [ ] と { })に必ず合わせる。配列の要素番号の始まりなど、記述形式で決まっていないことは、公開問題と同じく本文の中で注記する(例「配列の要素番号は 1 から始まる」)。
5. 必要なら2つ目の掛け合い `<div class="co talk t2">…</div>`(2〜3行、補足)。

- 文体: です/ます。1文は短く。専門用語は初出で一言説明。英字略語は初出で「略語(正式名、日本語)」。Markdown記号は使わない。<b> は強調に少しだけ。
